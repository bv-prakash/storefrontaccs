Custom product reviews on PDP and PLP (Mesh REST API)

================================================================================

PURPOSE

Shoppers see star ratings and review counts on PLP and PDP, open a Reviews tab on
the product page, read paginated reviews, and submit new reviews (name, title,
rating, body). Data is loaded and saved through an Adobe I/O Runtime / App Builder
REST API (get-ratings, create-review), not through Commerce storefront GraphQL.
The API base URL is set in config.json per store view; review content and
moderation live in your Mesh/backend service.

Repo: https://github.com/bv-prakash/storefrontaccs/

================================================================================

WHO DOES WHAT

Merchants / backend (Mesh / App Builder)
  - Deploy and maintain the product-reviews web actions (get-ratings, create-review).
  - Expose a stable base URL (example: https://.../api/v1/web/product-reviews).
  - Allow CORS for storefront origins: localhost:3000, *.aem.page, *.aem.live.
  - Return averageRating, reviewCount, reviews[], and pagination (page, limit, totalPages).
  - Run review moderation in your backend if reviews must be approved before display.

Authors (da.live / AEM)
  - Use the standard Product Details block on PDP (reviews are built in; no separate CMS block).
  - Ensure PDP includes the Reviews tab with this project's product-details layout.
  - PLP/category pages use Product List Page; stars show under the title when the API has reviews.
  - No extra block rows—UI is built at runtime from the API.

Shoppers
  - PDP under price: stars and "N Reviews" (opens Reviews tab), or Be the first reviewer.
  - PDP Reviews tab: summary, Write a Review (toggles form), list, 5 reviews per page with Previous/Next.
  - Write a review: stars, name, review title, review text, submit.
  - PLP: stars and review count under product name when reviews exist.

Developers / implementers
  - Built: scripts/product-reviews.js + scripts/components/product-reviews/ (UI/CSS).
  - Wired in: scripts/commerce.js, blocks/product-details/product-details.js,
    blocks/product-list-page/product-list-page.js.
  - Init: scripts/commerce.js -> initializeCommerce() -> initProductReviewsApi().
  - Full technical detail: scripts/components/product-reviews/README.md (in repo).

================================================================================

IF YOU DO NOT NEED PRODUCT REVIEWS

  - UI only: Remove PLP/PDP wiring and delete scripts/components/product-reviews/.
    See "Remove UI only" below. You may keep product-reviews-api-base in config.

  - Full removal: Also remove scripts/product-reviews.js, commerce.js init, and
    config keys. See "Remove full module" below.

================================================================================

SUPPORT CHECKLIST

  No stars on PDP or PLP
    -> product-reviews-api-base in config.json; browser Network tab for get-ratings;
       console for init warning.

  PLP stars missing but PDP works
    -> Rating must sit beside the title link, not inside it (CSS line-clamp).

  CORS / fetch failed
    -> Mesh runtime must allow your storefront origin.

  Submit fails
    -> POST create-review; required: sku, author, title, review, rating (1-5).

  Wrong stars / average
    -> API ratings should be 1-5; average drives half-star display (e.g. 3.5).

  Stale counts after submit
    -> Hard refresh; client cache clears for that SKU on successful submit.

  Wrong SKU on configurable products
    -> PDP must sync reviews when variant SKU changes.

  Pagination missing
    -> Need more than 5 reviews; API pagination.totalPages should be set.

================================================================================

CONFIGURATION (config.json)

Under public -> store key (default, /fr/, etc.):

  "product-reviews-api-base": "https://YOUR_NAMESPACE.adobeioruntime.net/api/v1/web/product-reviews"

default-site.json template:

  "product-reviews-api-base": "{PRODUCT_REVIEWS_API_BASE}"

Requests also send headers.all and headers.cs from the same store section when set.

================================================================================

API REFERENCE

  Get ratings and reviews
    GET {product-reviews-api-base}/get-ratings?sku={sku}&page={page}&limit={limit}

  Create review
    POST {product-reviews-api-base}/create-review

POST body fields:
  sku      Required  Current product SKU
  author   Required  Form: Your name
  title    Required  Form: Review title (max 255)
  review   Required  Form: Your review
  rating   Required  Integer 1-5 from star picker
